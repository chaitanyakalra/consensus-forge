License: MIT (recommended for open-source release)-----1. Project Overview


ConsensusForge is an innovative, open-source framework that combines persistent, autonomous AI agents with an evolving multi-LLM consensus mechanism.


Core Idea


Create personal or task-specific AI agents that run continuously (24/7), maintain long-term memory and state, perform actions via tools/skills, but — unlike single-model agents — make important decisions through a dynamic council of multiple LLMs. The council reviews, debates and synthesizes answers, significantly reducing hallucinations and improving reliability. Over time the system automatically learns which models perform best for which kinds of tasks and evolves the council composition.


Key Goals
* Build trustworthy long-running agents
* Achieve meaningful reduction in hallucinations without fine-tuning or huge RAG
* Make agents measurably smarter the longer they run
* Keep costs very low (using your existing API keys)
* Run locally or on cheap VPS
* Easy to extend and customize
Target Use Cases
* Personal finance/market watcher (NSE/Sensex tracking, alerts)
* Long-term research assistant
* Automated content generator with fact-checking
* Home automation / personal knowledge manager
* Domain-specific bots (education, coding helper, travel planner)

import os
import json
from google import genai                           # pip install google-generativeai
from xai_sdk import Client as GrokClient           # pip install xai-sdk
from openai import OpenAI                          # pip install openai


# Load keys from .env or environment
GEMINI_KEY = os.getenv("GEMINI_API_KEY")
GROK_KEY   = os.getenv("GROK_API_KEY")
OPENAI_KEY = os.getenv("OPENAI_API_KEY")


genai.configure(api_key=GEMINI_KEY)
grok_client = GrokClient(api_key=GROK_KEY)
openai_client = OpenAI(api_key=OPENAI_KEY)


DEFAULT_COUNCIL = [
    {"name": "gemini", "model": "gemini-1.5-flash"},
    {"name": "grok",   "model": "grok-beta"},
    # {"name": "gpt",    "model": "gpt-4o-mini"}   # uncomment when wanted
]


def call_llm(model_info, prompt):
    name = model_info["name"]
    if name == "gemini":
        model = genai.GenerativeModel(model_info["model"])
        resp = model.generate_content(prompt)
        return resp.text
    elif name == "grok":
        chat = grok_client.chat.create(model=model_info["model"])
        chat.append({"role": "user", "content": prompt})
        resp = chat.complete()
        return resp.content
    elif name == "gpt":
        resp = openai_client.chat.completions.create(
            model=model_info["model"],
            messages=[{"role": "user", "content": prompt}]
        )
        return resp.choices[0].message.content
    return "Error: unknown model"


def run_council(query, council=DEFAULT_COUNCIL, use_third=False):
    responses = []
    active_council = council if not use_third else council + [council[2]] if len(council) > 2 else council
    
    for model in active_council:
        try:
            answer = call_llm(model, query)
            responses.append({"model": model["name"], "answer": answer})
        except Exception as e:
            responses.append({"model": model["name"], "answer": f"Error: {str(e)}"})
    
    # Simple synthesis (can be improved)
    combined = "\n\n".join([f"[{r['model']}]: {r['answer']}" for r in responses])
    chairman_prompt = f"Review these answers and produce the best final response:\n\n{combined}"
    
    # Use Gemini as chairman (cheap & fast)
    final = call_llm({"name": "gemini", "model": "gemini-1.5-flash"}, chairman_prompt)
    
    return {
        "query": query,
        "responses": responses,
        "final": final
    }


# For CLI testing
if __name__ == "__main__":
    result = run_council("What is the current status of Indian stock market?")
    print(json.dumps(result, indent=2))

const { exec } = require('child_process');
const util = require('util');
const execPromise = util.promisify(exec);


async function runCouncil(query) {
  try {
    const cmd = `python3 council.py --query "${query.replace(/"/g, '\\\\"')}"`;
    const { stdout } = await execPromise(cmd, { cwd: '/path/to/consensus-forge' });
    return JSON.parse(stdout);
  } catch (err) {
    return { error: err.message };
  }
}
